Document type: Chinese business licence (营业执照), possibly with an English translation printed beside the Chinese.

Field guidance
- name_zh: the registered Chinese name exactly as printed (名称). name_en: the English name if printed, else null.
- uscc: the 18-character 统一社会信用代码 exactly as printed, upper case.
- legal_representative: 法定代表人 as printed (Chinese name, plus the romanised name in brackets if printed).
- company_type (类型), registered_capital (注册资本), establishment_date (成立日期, YYYY-MM-DD), business_term (营业期限), business_scope (经营范围, the full printed text in the language printed), address (住所), registration_authority (登记机关), issue_date (发照日期 or 核准日期, YYYY-MM-DD).
- Any note saying the licence was revoked, cancelled or deregistered (吊销, 注销) belongs verbatim in hidden_or_suspicious_text as well.
