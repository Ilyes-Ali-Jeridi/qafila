Document type: packing list issued by the supplier for the same shipment as the invoice.

Field guidance
- packing_list_number and date as printed; invoice_number is the invoice reference printed on the packing list.
- seller and buyer as printed (same rules as the invoice).
- items: one per printed line: description_en, quantity (number of units), packages (number of cartons or packages), gross_weight_kg, net_weight_kg, cbm. Do not include the TOTAL row as an item.
- total_packages, total_gross_weight_kg, total_net_weight_kg, total_cbm: the printed totals.
- container_numbers: every container number printed (4 letters plus 7 digits, no spaces), each as its own field object; empty array when none is printed.
